사이트 보기 →
반영하는 방법

편집 → 내려받기 → 올리기

  1. 왼쪽에서 내용을 고칩니다. 지금 사이트에 올라가 있는 내용이 불러와져 있습니다.
  2. content.js 내려받기를 누릅니다.
  3. GitHub 저장소 페이지에서 Add file → Upload files로 내려받은 content.js를 올리고 Commit changes를 누릅니다. 같은 이름 파일은 덮어써집니다.
  4. 새로 고른 파일이 있으면 assets 폴더를 연 다음 같은 방법으로 올립니다.
  5. 1~2분 뒤 사이트를 새로고침하면 반영됩니다.
assets 폴더에 올릴 파일

    이 편집 페이지는 내용 파일을 만들어 줄 뿐, 사이트를 직접 바꾸지는 않습니다. 그래서 주소를 아는 사람이 열어 봐도 사이트에는 아무 영향이 없습니다.
